#### 基本概念
1. character set (字符集)，多个字符的集合, 比如gb2312标准收录了大约7000多个字符
2. character coded set (编码字符集) ：给收录的每个字符一个数字编号(character code point)，比如 "啊" 这个字符在unicode字符集里面的数字编号是16进制数字 554A。 这个数字编号与字符映射关系的集合就是编码字符集。
3. character encoding (字符编码) , 编码字符集(character coded set) 里面的每一个数字编号(character code point)在计算机上存储时的具体二进制序列，比如 unicode 字符集里面的字符 "啊" （code point是 554A），如果采用utf8编码，那么具体的二进制序列是 \xE5\x95\x8A ， 如果采用 utf-16be 编码, 就是 \x55\x4A , 如果采用 UTF-16LE编码，就是 \x4A\x55

unicode 字符集有4种编码方式: UTF-8, UTF16-BE, UTF16-LE, UTF32。 其他常见的字符集只有一种编码方式，比如gbk,big5这些字符集，在收集字符，给字符数字编号后，直接使用大端方式确定了字符编码，比如gbk字符集的"好"字，数字编号是16进制数字 BAC3，他的字符编码是： \xBA\xC3
